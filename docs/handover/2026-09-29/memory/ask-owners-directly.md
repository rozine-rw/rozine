When Robert's (or any owner's) input has conflicts or gaps, post direct, numbered questions addressed to them in the same issue straight away. Each question needs short answer options (a/b) and a note on what each option changes. An engineering-style gap table is not enough.

**Why:** on 2026-09-29, Erastus said "pose the questions on the conflicts to Robert in the same issue. You should have done that a long time ago". My #154 gap list (5876485661) buried the questions in tables written for engineers, so Robert had nothing easy to answer. The numbered Q1–Q16 post (5885143755) is the model to follow.

**How to apply:**
- Lead with the questions and say what reply format is enough, e.g. "Q1 a, Q2 b".
- Group the questions by topic.
- Name the owner of each decision.
- Keep the engineering detail secondary.
